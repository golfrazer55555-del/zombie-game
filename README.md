# 좀비 생존 일지

위에서 내려다보는 픽셀아트 좀비 생존 게임입니다. 레벨업도 업그레이드도 없습니다.
집을 뒤져 물자를 모으고, 낚시하고, 도구를 만들고, 농사를 지으며 끝없이 버티세요.
컴퓨터(키보드·마우스)와 모바일(터치) 모두에서 브라우저로 실행됩니다.

모든 그림(캐릭터·좀비·지형·건물·아이템 아이콘)과 효과음은 외부 이미지·음원 파일 없이 **코드로 생성**합니다.

## 바로 해보기

- **한 파일 버전**: `dist/zombie-survival.html` 을 내려받아 브라우저로 열면 됩니다 (휴대폰도 가능).
- **폴더 버전**: `index.html` 을 브라우저로 엽니다.
- **인터넷 주소로 공유**: 저장소 설정 → Pages → *Deploy from a branch* 에서 이 브랜치의 `/ (root)` 를 고르면
  `https://<아이디>.github.io/zombie-game/` 주소로 누구나 플레이할 수 있습니다.

진행 상황은 브라우저에 자동 저장되며(1분마다, 잠잘 때, 창을 닫을 때) 타이틀의 **이어하기**로 계속할 수 있습니다.
죽으면 저장은 사라집니다.

## 조작법

| 동작 | 컴퓨터 | 모바일 |
|---|---|---|
| 이동 | WASD · 방향키 | 화면 왼쪽을 끌기 (조이스틱) |
| 달리기 | Shift (누르는 동안) | 달리기 버튼 (켜기/끄기) |
| 조준 | 마우스 | 자동 조준, 공격 버튼을 누른 채 끌면 그 방향 |
| 공격 / 들고 있는 물건 사용 | 왼쪽 클릭 · Space | 공격 버튼 (들고 있는 물건에 따라 먹기·설치·던지기·낚시로 바뀜) |
| 줍기·열기·문·잠자기 | E · 오른쪽 클릭 | 손 버튼 |
| 재장전 / 손전등 | R / F | 장전 / 손전등 버튼 |
| 핫바 선택 | 1~6 · 마우스 휠 | 아래 핫바 누르기 |
| 가방 / 제작 / 지도 | I(Tab) / C / M | 오른쪽 위 버튼 |
| 일시정지 | Esc | 일시정지 버튼 |

## 게임의 규칙

- **난이도 곡선 없음**: 좀비 수·속도·체력, 특수 좀비 비율, 아이템 양, 배고픔 속도, 하루 길이, 좀비 재생성 여부를
  시작 전에 정하면 끝까지 그대로입니다. (프리셋: 쉬움 / 보통 / 어려움 / 악몽)
- **생존 수치**: 체력, 배고픔, 갈증, 피로. 굶거나 목마르면 체력이 줄고, 배부르고 목마르지 않으면 서서히 회복합니다.
- **상태 이상**: 좀비에게 물리면 출혈(붕대로 지혈), 날생선·흙탕물을 먹으면 병(항생제 또는 시간이 지나면 회복).
- **소음**: 발소리, 타격음, 총성, 깨지는 유리는 좀비를 불러 모읍니다. 총은 강하지만 아주 시끄럽습니다.
  빈 병이나 폭죽을 던지면 좀비를 다른 곳으로 유인할 수 있습니다.
- **시야**: 벽 너머는 보이지 않습니다. 밤에는 어둡고 좀비도 잘 보지 못하지만, 손전등을 켜면 좀비 눈에도 잘 띕니다.
- **건물**: 밖에서는 지붕만 보이고 안에 들어가야 내부가 보입니다. 닫힌 문은 좀비가 부숴야 들어올 수 있고,
  창문은 깨질 수 있습니다. 깨진 창문과 부서진 문틀에는 바리케이드를 세우고, 망치로 수리하세요.
- **잠**: 침대나 침낭에서 잡니다. 근처에 좀비가 있으면 잠들 수 없고, 자는 동안 공격받으면 깹니다.

## 좀비

| 종류 | 특징 |
|---|---|
| 일반 좀비 | 느리게 걷는다. 가장 흔하다. |
| 빠른 좀비 | 달리는 사람만큼 빠르다. 밤에는 빨간 눈이 빛난다. |
| 덩치 큰 좀비 | 아주 튼튼하고 한 방이 세다. 문과 바리케이드를 금방 부순다. |
| 기어다니는 좀비 | 다리를 잃고 바닥을 긴다. 느리지만 발목을 붙잡아 움직임을 늦춘다. |

## 살아남는 방법

- **파밍**: 냉장고, 찬장, 서랍장, 옷장, 약장, 상점 진열대, 경찰서 보관함, 자동차 트렁크, 쓰레기통…
  편의점·약국·철물점·경찰서·주유소·창고·농장·낚시터 오두막마다 나오는 물건이 다릅니다.
- **낚시**: 낚싯대를 들고 물을 바라보며 사용 → 찌가 흔들리면 누르고 → 막대가 초록 구간에 왔을 때 다시 누릅니다.
- **요리**: 모닥불 근처에서 생선 굽기, 흙탕물 끓이기, 라면 끓이기, 감자 굽기, 채소 수프.
- **제작**: 천 조각·끈·붕대·판자·횃불·모닥불·바리케이드·보관함·침낭·낚싯대·돌도끼·나무 창·못 박힌 방망이·활·화살·화염병.
- **자연**: 도끼로 나무를 베면 통나무, 덤불에서 나뭇가지와 산딸기, 숲 바닥에서 돌과 나뭇가지를 줍습니다.
- **농사**: 감자·당근 씨앗을 풀밭에 심으면 하루 반 뒤 수확합니다.

## 프로젝트 구조

```
index.html          진입점
css/style.css       UI 스타일 (픽셀 단위 --u 기반)
js/util.js          난수, 노이즈, 저장소 등 공용 함수
js/data.js          아이템, 제작법, 전리품, 좀비, 난이도 설정
js/sprites.js       픽셀아트 엔진 + 캐릭터/자연물/구조물 생성
js/icons.js         아이템·UI 아이콘 생성
js/tiles.js         지형·벽·가구·지붕 생성
js/world.js         월드 생성(마을, 건물 내부, 호수, 숲, 농장)과 충돌/시야 판정
js/audio.js         Web Audio 효과음·환경음 합성
js/game.js          플레이어, 좀비 AI, 전투, 아이템 사용, 제작, 낚시, 잠, 저장
js/render.js        저해상도 캔버스 렌더링, 조명, 시야 안개
js/input.js         키보드·마우스·터치 입력
js/ui.js            HUD, 가방, 제작, 보관함, 지도, 메뉴, 터치 버튼
js/main.js          부팅, 메인 루프, 화면 전환
tools/build.js      한 파일 HTML로 묶기 (node tools/build.js → dist/)
tools/subset-fonts.py  사용하는 글자만 남겨 폰트 크기 줄이기
fonts/              갈무리11 픽셀 폰트(일부 글자만), OFL 라이선스
```

코드를 고친 뒤 `node tools/build.js` 를 실행하면 `dist/zombie-survival.html` 이 다시 만들어집니다.
새 한글 문구를 추가했다면 `python3 tools/subset-fonts.py <Galmuri11.woff2> <Galmuri11-Bold.woff2>` 로 폰트도 다시 만드세요.
